# QuantLab — مختبر البحث الكمي (XAUUSD / EURUSD)

مشروع بحثي مستقل وقابل لإعادة الإنتاج. هدفه اكتشاف أفضلية إحصائية حقيقية **بعد التكاليف** وخارج العينة، وليس إنتاج استراتيجية تبدو مربحة تاريخياً. النتيجة السلبية نتيجة مقبولة.

## الحالة الحالية
| الجزء | الحالة |
|---|---|
| هيكل المشروع، البروتوكول، السجل المُسلسَل بالتجزئة | جاهز ومُختبَر |
| فاحص جودة البيانات + فحص التوافق بين الأطر | جاهز ومُختبَر على بيانات صناعية |
| ختم HOLD وفتحه مرة واحدة | جاهز ومُختبَر |
| محرك الاختبار + التكلفة لكل صفقة + 4 سيناريوهات | جاهز ومُختبَر بحالات محسوبة يدوياً |
| دراسة الأحداث، المجموعة الضابطة، اختبار الاقتطاع (look-ahead) | جاهز ومُختبَر |
| الشارتات، إعادة التشغيل بلا مستقبل، أمثلة رابحة وخاسرة، فيديو | جاهز ومُختبَر |
| الواجهة (Streamlit) | تعمل آلياً بلا أخطاء؛ لم أرها بعين مستخدم |
| سكربت تصدير MT5 `mt5/QuantLab_Export.mq5` | **لم يُترجَم (compile) بعد** — لا أملك MetaEditor هنا |
| بيانات حقيقية | **لا توجد بعد** — بانتظار ملفاتك |
| أي استراتيجية أو Expert Advisor | **لم تُكتب عمداً** حتى يُقفل البروتوكول وتنجح الاختبارات |

الاختبارات الآلية (`python -m pytest tests -q`) تتحقق من الكود فقط، بالبيانات الصناعية. لا تُعدّ دليلاً على أي أفضلية في السوق.

## خطواتك (واحدة فقط الآن)
1. افتح MetaEditor وافتح `mt5/QuantLab_Export.mq5` ثم اضغط F7 للترجمة. **إن ظهر خطأ فانسخه لي كما هو.**
2. شغّله كسكربت على أي شارت. اضبط `InpSymbols` إن كانت أسماء الرموز عند وسيطك مختلفة (مثل XAUUSDm).
3. ستجد الملفات في `...\MetaQuotes\Terminal\Common\Files\QuantLab\`. ارفعها هنا كلها (`QL_*.csv`). ابدأ بـ D1 وH4 إن كانت M15 كبيرة.
4. أخبرني: اسم الوسيط، **عمولة الوسيط الفعلية لكل لوت (ذهاب وإياب) لكل رمز**، ونوع الحساب. بدونها تبقى أرقام التكلفة في `protocol_params.json` افتراضات مؤقتة.

## ما سيحدث بعد رفع البيانات
`ingest` ← `validate` ← أُبلغك بما هو صالح وما ينقص ← نراجع التكاليف والتواريخ ← `lock-protocol` ← بعدها فقط تبدأ الاختبارات.

## الأوامر (عند التشغيل على جهازك)
```
pip install -e .
python -m quantlab.cli ingest            # يستورد data/incoming ويفصل HOLD ويفحص الجودة
python -m quantlab.cli validate          # تقرير reports/data_quality_report.md
python -m quantlab.cli lock-protocol     # يقفل البروتوكول (لا رجعة)
python -m quantlab.cli status
streamlit run app/dashboard.py
```

## الضمانات المبرمجة (وما لا تضمنه)
- لا تجربة تُسجَّل قبل قفل البروتوكول، وأي تعديل بعده يوقف التسجيل.
- DEV للاستكشاف فقط؛ VALID بعد تجميد الإعدادات بالضبط؛ HOLD مرة واحدة، فقط للفرضيات الناجحة في VALID، ولا يُعاد.
- دالة الإشارات التي تتغير عند حذف الشموع المستقبلية تُرفض.
- كل تجربة تُحتسب في تصحيح تعدد الاختبارات؛ السجل مُسلسَل بالتجزئة وأي تعديل في تاريخه يُكتشف.
- بيانات صناعية لا تُسجَّل كبحث أبداً.
- **حدود صريحة:** قفل HOLD إجرائي لا تشفيري (الملفات على جهازك). يمنع الخطأ العرضي ويُثبت عدم التعديل، ولا يمنع من يتحايل عمداً. وبيانات الشموع هي أسعار Bid؛ سبريد MT5 المخزّن هو سبريد افتتاح الشمعة لا متوسطها.
